# 🏙️ City Idle - Unity Game

**City Idle** is a casual mobile idle/clicker game built with **Unity 2018.2.5f1**, supporting both **Android** and **iOS** platforms. Players build and manage their virtual city, earning resources even when offline. Perfect for casual gamers who enjoy tycoon and city-building games.  

---

## 🎮 Overview
City Idle lets players:  
- Build and expand a virtual city  
- Earn resources passively with idle mechanics  
- Enjoy mobile-optimized gameplay  
- Experience immersive sound and music  

---

## 🚀 Features
- ✅ **Idle Gameplay**: Earn resources even when the game is closed  
- 🏗 **City Building**: Construct and expand your virtual city  
- 📱 **Mobile Optimized**: Smooth performance on Android & iOS  
- 💰 **Monetization**: Integrated Google Mobile Ads (AdMob)  
- 🗺 **Tilemap System**: Advanced 2D tilemap-based level design  
- 🎵 **Sound & Music**: Audio system for immersive gameplay  
- 🧩 **Prefab System**: Modular game object prefabs for easy customization

## ⚙️ Requirements
- **Unity Version:** 2018.2.5f1 or compatible  
- **Target Platforms:** Android & iOS  
- **Scripting Backend:** Mono (.NET Framework 3.5)  

---

## 🛠 Installation
1. Clone or download this repository  
2. Open the project in **Unity 2018.2.5f1**  
3. Navigate to the main scene in `Assets/Scenes/`  
4. Press **Play** to test the game in the editor  

---

## 📱 Building for Platforms

### Android Build
1. Go to **File > Build Settings**  
2. Select **Android** as the target platform  
3. Configure Android player settings  
4. Click **Build** and choose your output APK path  

### iOS Build
1. Go to **File > Build Settings**  
2. Select **iOS** as the target platform  
3. Configure iOS player settings  
4. Click **Build and Run** (requires Xcode on macOS)  

---

## 💰 Monetization
This project includes **Google Mobile Ads (AdMob)** integration.  

Steps to set up ads:  
1. Import the `"Import ME, IM ADMOB!.unitypackage"` file from `Assets/`  
2. Configure your **AdMob App ID** and **Ad Unit IDs** in the game settings  
3. Implement ad placement in your game scripts
